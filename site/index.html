Über mich

Ich schreibe Software meistens dann, wenn mir oder Leuten um mich herum ein Werkzeug fehlt.

So ist ein Trainingsserver für das CS2-Team entstanden, eine Kasse für den Verein und ein Überblick über meine eigenen KI-Kosten. Am liebsten arbeite ich mit TypeScript, React und Convex. Wenn es schnell und nah am System sein muss, mit Rust.

Auf GitHub seit 2020, als realS3BI.
